# ASTP-Net
Asymmetric synaptic plasticity gates θ−γ cognitive rhythms and dictates pathological lock-in

License: MIT
(Note: If the paper is accepted, you can add a link to the published paper here)

This repository contains the custom computational neuroscience code and data analysis scripts for the manuscript:

"Asymmetric synaptic plasticity gates θ−γ cognitive rhythms and dictates pathological lock-in" Submitted to eNeuro (2026).

📌 Overview

This repository provides an exact macroscopic neural mass model dynamically coupled with a microscopic network of Quadratic Integrate-and-Fire (QIF) spiking neurons.

Unlike traditional models that assume symmetric synaptic resource depletion, this framework implements biologically realistic, target-specific (asymmetric) Short-Term Plasticity (STP). The code demonstrates how this asymmetry breaks structural rigidity, generates a bistable dynamic regime, and provides the required hysteresis for robust θ−γ Phase-Amplitude Coupling (PAC) — a hallmark of cognitive flexibility.

📂 Repository Structure

The repository includes three core Fortran 90 programs for numerical simulation and one Jupyter Notebook for data processing and visualization.

1. Fortran Simulation Codes (.f90)
SpikingNetwork_AsymmetricSTP.f90
The baseline asymmetric paradigm without external periodic forcing. Simulates the core bistable regime and hysteresis topological boundaries.
SpikingNetwork_AsymmetricSTP_Theta.f90
The main experimental model. Implements target-specific STP (excluding recurrent E-to-E connections) and introduces top-down 
θ (5 Hz) periodic forcing. Demonstrates robust cross-frequency coupling and delayed γ quenching.
SpikingNetwork_SymmetricSTP_Theta.f90
The control paradigm. Applies STP symmetrically across all E and I populations under identical θ forcing. Demonstrates a locked, rigid state with weak passive entrainment.
2. Data Visualization (.ipynb)
figure.ipynb
A comprehensive Python notebook. It reads the .dat outputs generated by the Fortran simulations to reproduce the main figures of the manuscript (e.g., macroscopic firing rate series, microscopic spike raster plots, Phase-Amplitude Coupling comodulograms, and Modulation Index calculations).
⚙️ System Requirements

Fortran Compiler: gfortran (GNU Fortran) or ifort (Intel Fortran).
Python Environment: Python 3.8+ with numpy, scipy, and matplotlib.
Jupyter: To run the .ipynb notebook.
No specialized hardware or supercomputing clusters are required. The simulations can be executed on standard modern desktop computers.

🚀 Usage Instructions

Step 1: Compile the Fortran Code
Open your terminal, navigate to the repository directory, and compile your desired model using gfortran with high-level optimization (-O3 is highly recommended for speed):

Bash

gfortran -O3 SpikingNetwork_AsymmetricSTP_Theta.f90 -o sim_asymmetric
Step 2: Run the Simulation
Execute the compiled binary:

Bash

./sim_asymmetric
Depending on your CPU, the simulation of 5,000 interacting neurons over 1,000+ ms may take a few minutes. Upon completion, several .dat files will be generated in the same directory.

Step 3: Output Data Description
The Fortran program outputs several data files used for plotting:

atime*.dat: Macroscopic time series (time, global/E/I firing rates, mean voltages, theta forcing signal).
atheory*.dat: Macroscopic mean-field state variables (e.g., r_e, r_i, v_e, v_i, x_e, x_i).
av0e*.dat / av0i*.dat: Spike timing data for Excitatory and Inhibitory neurons (used for raster plots).
acv*.dat: Statistical metrics (Coefficient of Variation, Kuramoto synchronization order parameter ρ).
Step 4: Visualize Results
Launch Jupyter Notebook and open figure.ipynb:

Bash

jupyter notebook figure.ipynb
Run the cells sequentially. The notebook is configured to read the generated .dat files and plot the bifurcation diagrams, time series, and PAC comodulograms.
